# zojalabs-com

Website for Zoja Labs. Static site: `index.html` at the repo root.

## Hosting

- Vercel project `zojalabs-com`, deployed from GitHub: https://github.com/tomasz-czarnecki/zojalabs-com
- Branch: `main`

## Domains

Canonical domain: **www.zojalabs.com**

| Domain                    | Behaviour                          |
|---------------------------|------------------------------------|
| www.zojalabs.com          | Production (canonical)             |
| zojalabs-com.vercel.app   | Production (Vercel default domain) |
| zojalabs.com              | 308 redirect → www.zojalabs.com    |
| zoja.ai                   | 307 redirect → www.zojalabs.com    |
| www.zoja.ai               | 307 redirect → www.zojalabs.com    |
